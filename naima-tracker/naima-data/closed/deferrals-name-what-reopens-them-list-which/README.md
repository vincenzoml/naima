# Deferrals name what reopens them; a list of which documents are authoritative

A deferral with a reason is still re-argued when nothing says what would reopen it; parallel status documents compete with the trackers and an agent plans from the wrong one.

Done: a `parked`, `wontfix` or `dropped` item can carry `reopensWhen` (prose or a link); `naima view parked` lists each with its trigger; project config lists its authoritative documents and the retired ones, and `naima guide` prints that list; a rule says no new status/summary document, update the authoritative one; a check notes a retired document still linked from a steering document.
