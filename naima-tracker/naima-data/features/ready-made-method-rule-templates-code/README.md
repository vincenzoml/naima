# Ready-made method-rule templates for code

Some lessons recur in every project: two copies of one predicate where only one gets fixed; a 'do not restore' comment that stops nobody; user state written into shipped files; overlays keyed by id that are never reaped.

Done: Naima ships 4-6 optional rule templates (`rules` type, audience agents), each with its reason and the failure it prevents; `naima rules` shows the ones a project enables; none enabled by default.
