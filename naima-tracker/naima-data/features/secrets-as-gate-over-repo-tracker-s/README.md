# Secrets as a gate over the repo and the tracker's attachments

Attachments are permanent once committed, and a key leaked through one three times in a comparable method, from one cause.

Done: `naima check` reports a private-key body or API-key pattern in tracked files and attachments; a header with no body after it is not flagged; each exception lives in config with a reason and an item id, and the exception list only shrinks; a test feeds six secret shapes and requires each caught; the reporting flow says to redact before attaching.
