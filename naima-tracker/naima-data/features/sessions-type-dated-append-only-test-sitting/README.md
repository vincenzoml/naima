# `sessions` type: dated, append-only test-sitting records

The routing table has no home for dated test results either. An audit of a comparable method found this practice nearly dead there (10 files, none touched in three weeks) — lower priority than an earlier reading assumed; results written directly on the test item as they happen carry most of the value.

Done: a `sessions` type (dated, append-only, one per test sitting); tests can be grouped into a run; documented as optional, not a daily habit to enforce.
