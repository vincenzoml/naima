# Capture now, act later, always

Whenever the owner, in chat, asks for a feature, reports a problem, makes a
decision or defers something, file it at once — in the background, without
derailing the work underway — restated in the agent's own words, never the
chat verbatim. Search duplicates first (`naima list`, or `naima new
--dedupe`) and link instead of refiling; triage it on the spot (impact,
priority, confidence); record a decision with `decisions`, a deferral with
its reason. This holds always, not only when a report flow is explicitly
invoked. "I already told you" means a report was lost: file it now and say
it was missing.

Why: a report said once and not filed is a report the owner will have to
make again, and a second telling is a sign the first was never captured.
