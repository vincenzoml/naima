# naima ui's boards, claims, session notes and item views look right to the owner

1. In a project with a few items, a test verifying one of them, a claim on
   two branches and a session note, run `naima ui`.
2. On **Home**, below next up, read the claims panel: who holds what, on which
   branch, and the items held twice.
3. Open **Boards**, pick each type, tick "with the done items".
4. Open **Session notes**; change how many.
5. Follow an item link to **Item**: the evidence first, then fields, links
   and page; pick another item by its reference.
6. Use the keyboard only once through: every control is reachable and named.

Pass: the owner finds each view clear and readable, and says what the look
and feel should become. The design is the owner's call; this proves only
that what is there reads well enough to build on.
