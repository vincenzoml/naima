# naima ui's first screen looks right to the owner

The gesture that proves it, step by step, and what a pass looks like.

1. In a project with a gate and a few open items, run `naima ui`.
2. The window opens on **Home**: the summary, then the gates, then next up.
3. Read it as you would read `naima summary`, `naima gates` and
   `naima view next`: nothing is missing, nothing is hard to find.
4. Open a gate's blocking list; follow the Metrics, Timeline and Coverage tabs.

Pass: the owner finds the first screen clear and readable, and says what the
look and feel should become. The design is the owner's call; this proves only
that what is there reads well enough to build on.
