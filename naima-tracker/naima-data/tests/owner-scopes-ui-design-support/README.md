# The owner scopes UI design support

## Gesture

The owner says what UI design support should be — layout guidance, a design-system reference, a check against it, or something else — and what is out of scope. The agent writes it on features/ui-design-support-planned.

Pass: the scope is written on the feature, in the owner's decision. `runBy: human`, `humanBecause: decision`: the scope of a feature nobody has asked for in detail is the owner's call.
