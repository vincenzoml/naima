# Agent-flow safety rules stated and checked per flow page

The vision extends formal treatment to agent behaviour; nothing does yet.

Done: each flow page lists its safety rules as statements ('no worker merges', 'no branch closes its own claims', 'the owner is never the reason work resumes', 'one question at a time'); each is marked checked, specified or convention; the ones checkable from git and the tracker (worker branches never merged by the worker, trunk commits only by fast-forward) are checks or property items; the rest are filed as candidate properties for a later model.
