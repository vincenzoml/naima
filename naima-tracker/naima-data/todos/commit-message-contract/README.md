# Commit-message contract

A message that names functions instead of effects cannot be read by the owner; a message that hides what was not verified live turns into a false 'done' later.

Done: a commit-flow page says one commit does one thing; the subject says what changes for whoever uses the result; the body says what was not verified live, when that applies, and which tokens are reserved for the human verdict so an agent never writes one; an optional hook warns when a commit setting `fixedOn` has no verified/not-verified line.
