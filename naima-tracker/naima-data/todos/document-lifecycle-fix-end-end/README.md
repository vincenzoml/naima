# Document the lifecycle of a fix end to end

The lifecycle of a fix and every action it entails (claim, worktree creation, work, prove, close) is requested written down explicitly, including that every Naima-created worktree carries a claim.

Done: a docs page walks the lifecycle step by step, each step naming its command; cross-linked with the worktree-naming item's enforced rule and with closing-a-worktree.md.
