# The paper's pre-submission checklist is invisible as tracker items

The paper's pre-submission list (TLC run, case-study properties, self-hosted evaluation, measurements) lives only in the paper's README; the open todo for the research paper does not break it down.

Done: each line of that list is an item linked `blocks` to the paper todo; the case-study properties are filed as property items (open) in the case-study repository; a gate named for the paper holds them, so `naima queue` shows the deadline work.
