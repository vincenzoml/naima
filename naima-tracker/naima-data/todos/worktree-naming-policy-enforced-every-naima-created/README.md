# Worktree naming policy, enforced; every Naima-created worktree carries a claim

A strict, enforced naming policy for worktrees and branches is requested, and 'every worktree carries a claim' should be an explicit, checked rule rather than an assumption.

Done: the naming scheme is written down (what a worktree/branch name must contain); a check fails a worktree with no matching claim file, and fails a name that does not match the scheme; the opening-a-worktree flow page states both as rules.
