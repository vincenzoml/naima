# Naima, the program

**Website: [vincenzoml.github.io/naima](https://vincenzoml.github.io/naima/)**

This folder is the Naima a project runs: in a project it is
`naima-tracker/naima/`, and it holds nothing else — no tests, no development
files, none of Naima's own items.

- Run it from the project: `deno run -A naima-tracker/naima/naima.ts <command>`;
  `naima guide` prints where the documentation below is.
- People: [the documentation](docs/README.md), starting with
  [installing and updating](docs/guide/install.md).
- Agents: [the skill](skills/naima/SKILL.md).
